MOSAIC

مساعد ذكي يتعلم باستمرار من تصحيحاتك

لم أستطع الوصول إلى نواة MOSAIC على العنوان المحفوظ. تأكد أنها تعمل، ثم اضغط «اتصال».

اتصل بنواة MOSAIC

على نفس الجوال استخدم http://127.0.0.1:8765. على حاسوب في شبكة بيتك استخدم عنوانه، مثل http://192.168.1.20:8765.

تشغيل النواة على هذا الجوال (مرة واحدة)

1
ثبّت تطبيق Termux من F-Droid.
2
افتح Termux والصق: 
pkg update -y && pkg install -y python git
git clone -b ccr-253e89f3-o4rrym https://github.com/khalilo-cs/institute-webset2-repo
cd institute-webset2-repo/mosaic
python -m mosaic serve
3
ارجع هنا واضغط «اتصال». في المرات القادمة يكفي في Termux: 
cd institute-webset2-repo/mosaic && python -m mosaic serve

للحصول على ذكاء Claude في المحادثة

أنشئ مفتاحًا من console.anthropic.com ثم شغّل النواة هكذا بدل الأمر السابق:

ANTHROPIC_API_KEY=ضع_مفتاحك_هنا python -m mosaic serve --llm anthropic

بدون مفتاح يعمل MOSAIC من ذاكرته فقط، أو مع نموذج محلي عبر Ollama.
